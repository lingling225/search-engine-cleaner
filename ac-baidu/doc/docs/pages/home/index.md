# Search Engine Cleaner

Search Engine Cleaner 是 AC-Baidu 的精简维护分支，保留百度、Google、Bing、DuckDuckGo、360 / 好搜的完整搜索增强与自定义配置能力。

- 去除搜索结果跳转链接，尽可能直达原始网址
- 清理明确广告，支持域名与网址规则拦截
- 自动翻页、Favicon、结果编号与右侧栏控制
- 单列、居中、双列、三列和四列显示模式
- 护眼、暗色、背景图与自定义 Less.js 样式

## 支持网站

| 搜索引擎 | 主要能力 |
| --- | --- |
| 百度 | 重定向、广告清理、拦截、自动翻页、布局与主题 |
| Google | 重定向、广告清理、拦截、自动翻页、布局与主题 |
| Bing | 重定向、广告清理、拦截、自动翻页、布局与主题 |
| DuckDuckGo | 新标签优化、自动翻页、布局与主题 |
| 360 / 好搜 | 重定向、广告清理、拦截、布局与主题 |

## 配置

安装用户脚本后打开[配置中心](/pages/custom/)。配置页通过 `AC_GM_Interface` 与用户脚本通信，修改可以即时同步预览，点击保存后写入脚本配置。

项目与问题反馈：[lingling225/search-engine-cleaner](https://github.com/lingling225/search-engine-cleaner)
