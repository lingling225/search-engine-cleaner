# 安装说明

1. 安装用户脚本管理器，例如 [Tampermonkey](https://www.tampermonkey.net/)。
2. 从项目发布的 `Search-Engine-Cleaner.user.js` 安装脚本。
3. 打开[配置中心](/pages/custom/)，确认顶部显示“已连接用户脚本”。

浏览器扩展商店：

- [Chrome 应用商店](https://chrome.google.com/webstore/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd)
- [Firefox 附加组件](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
- [Safari App Store](https://apps.apple.com/us/app/tampermonkey/id1482490089)

Chrome 和 Edge 使用 Manifest V3 时，需要在扩展管理页开启开发者模式，Tampermonkey 才能正常执行用户脚本。

安装或运行异常请到 [GitHub Issues](https://github.com/lingling225/search-engine-cleaner/issues) 反馈，并附浏览器、用户脚本管理器、脚本版本和完整页面截图。
